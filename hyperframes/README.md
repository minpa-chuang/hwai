# Hyperframes: 中華醫事科技大學 30 秒直式形象片

This folder contains a Hyperframes-ready creative package for a 30-second, 9:16 vertical promotional video for **中華醫事科技大學**.

## Files

- `chmu-promo-vertical.html` — a self-contained browser animatic with kinetic Traditional Chinese typography, 30-second timing, cinematic transitions, particles, light streaks, and vertical framing.
- `storyboard.json` — structured production direction with timeline, text, motion, audio, camera, effect, and delivery notes.

## Preview

Open the HTML file directly in a browser, or run a local static server from the repository root:

```bash
python3 -m http.server 8080
```

Then visit:

```text
http://localhost:8080/hyperframes/chmu-promo-vertical.html
```

## Production Notes

- The animatic intentionally uses CSS-generated abstract visuals so it can be committed without licensed footage.
- Replace abstract visuals with approved campus footage, department labs, student scenes, and the official logo for final rendering.
- The edit is timed around a 30-second loop with a strong 0-2 second hook and scene changes at least every second for mobile retention.
